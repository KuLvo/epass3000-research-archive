# 文件签名与 SSH 认证

实现独立日常工具，使用现有槽位 1，不加入初始化、擦除、生成密钥命令。
组件为 USB R6/APDU 传输、卡内签名、公钥解析、文件验签、Paramiko SSH 密钥适配、中文界面。
公钥为 BER 长度字段配合小端整数；2048 位运算拆分为 MSE 64 字节和 PSO 192 字节。
签名使用标准 SHA-256 DigestInfo 和 PKCS#1 v1.5 填充，卡片返回签名后由 cryptography 独立验证。
所有 APDU 均核对完整状态码，PIN 不自动重试，SSH 禁用 SHA-1 并严格核验服务器主机密钥。

验证：5 项离线测试通过；真实设备签名验签通过、篡改文件拒绝；真实设备 SSH rsa-sha2-256 签名由 Paramiko 独立验证，篡改认证数据拒绝。
逐一复核函数及组合流程；未连接外部 SSH 服务器。GUI 提供启动入口，GUI 点击操作仍需用户验证。
