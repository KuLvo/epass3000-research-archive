# SSH 完整交互终端

在原 SSH 窗口增加“打开完整终端”，使用独立 Windows 控制台、VT 输入输出、UTF-8 和 SSH PTY，支持远端交互式 shell、sudo、vim、方向键和 Ctrl+C。窗口尺寸变化同步至远端。
PIN 仅在新窗口输入，不传入命令行、不存储；已有服务器指纹必须先经 GUI 确认，连接时严格匹配。认证仍由现有卡内私钥完成，关闭卡句柄后保留 SSH 会话。
没有加入初始化、擦除或密钥变更操作。终端退出关闭 SSH 连接并恢复控制台模式和编码页。
测试覆盖输入输出字节不变、中文/方向键/Ctrl+C、VT 清屏序列、PTY 尺寸同步、主机信任文件、部分写入；继承真实设备回环 SSH 登录测试。尚未人工连接外部服务器运行 sudo/vim，实际程序行为依赖远端安装及权限。
