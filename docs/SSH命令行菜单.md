# SSH 命令行菜单

增加 SSH菜单.cmd 和 python ssh_cli.py。主菜单为配置服务器、连接服务器、退出；配置支持添加并推送公钥、重新推送和删除本地记录。
推送前核对服务器指纹，以用户当次输入的服务器密码认证，通过 SFTP 追加 authorized_keys，不覆盖旧密钥，已有同一公钥时跳过，保留原有限制；拒绝符号链接和非普通路径。设置 .ssh 700、authorized_keys 600。目标为 Unix/Linux 默认 ~/.ssh 配置，特殊 AuthorizedKeysFile 或 Windows 服务端需管理员配置。
密码、PIN 不保存。连接用 USB Key 公钥认证并请求远端默认 shell，通过子进程复用交互终端，退出返回菜单。删除本地记录不移除服务器授权。
服务器禁用密码登录或 SFTP 时无法自动推送，保留本地记录供重试，可通过管理员安装公钥。新增测试覆盖配置持久化、追加保留、不重复安装、已有受限密钥保留和符号链接拒绝。
