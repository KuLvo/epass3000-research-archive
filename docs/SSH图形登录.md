# SSH 图形登录

新增中文 SSH 窗口：导出并复制公钥，记录主机端口用户名，首次连接显示 SHA256 指纹并经用户确认保存，已记录主机密钥变化时拒绝连接。PIN 不保存、不自动重试。
基于现有卡内密钥执行 rsa-sha2-256 认证。连接操作放在线程中，界面通过队列更新。提供非交互命令执行，20 秒读取超时、输出限制 1 MiB；断开及窗口关闭释放连接。
这属于普通 SSH 公钥认证，不是 SSH CA 签发证书。公钥安装仍需目标服务器管理员完成。本机测试服务仅监听回环地址，测试完整协议握手、公钥认证及主机密钥不匹配拒绝。

验证结果：9 项测试全部通过，包含真实 ePass3000 的回环 SSH 完整握手与认证，以及错误主机密钥拒绝。修复 TokenSSHKey 缺少 public_blob 字段导致的认证兼容问题。外部服务器尚未测试。
